# Matcap Generator

画像編集ソフトを使わずに、Unity の Inspector 上でパラメータを調整しながら Matcap 用のテクスチャを作成できるエディタ拡張です。

専用の `.matcapgen` ファイルをマテリアル（lilToon など）の Matcap スロットに割り当てておくと、Inspector で色やハイライトを変えた瞬間にシーン上のアバターの見た目もリアルタイムで追従します。スライダーをドラッグしている最中にもすぐ反映されるため、アバターの質感を見ながら直感的に調整できます。

## できること・できないこと

### できること
- Unity 上で「円形グラデーション」と「円形の光点・影（デカール）」を組み合わせて Matcap を作成する
- 作成した `.matcapgen` ファイルを通常のテクスチャと同じように lilToon などのマテリアルへドラッグして割り当てる
- アバターの見た目を見ながらリアルタイムに調整する（変更は自動保存）
- 作成した Matcap を通常の PNG 画像として書き出す

### できないこと（仕様上の制限）
- 楕円形のデカール
- ノイズの追加
- 任意の画像をスタンプとして重ねる機能

シンプルなグラデーション＋ハイライト／影の Matcap を Unity 上で素早く作りたい用途に向いています。

## 対応環境

- Unity 2022.3

## 導入方法

### VCC / ALCOM を使う方法（推奨）

1. 作者の VPM リポジトリ URL を VCC または ALCOM に追加します。
   - VPM リポジトリ URL: `https://anosionv.github.io/vpm/index.json`
2. 対象のプロジェクトの管理画面を開き、パッケージ一覧から **Matcap Generator**（`jp.anosion.matcap-generator`）を追加します。

### Releases から導入する方法

GitHub の Releases ページから `.unitypackage` または `.zip` をダウンロードして導入することもできます。

## 使い方（最初の Matcap を作るまで）

1. **Matcap ファイルを作成する**
   Project ビューの何もないところで右クリックし、**「Create」→「Anosion」→「Matcap テクスチャ」** を選びます。
   「新しい Matcap」という名前のファイル（`.matcapgen`）が作成されます（初期状態は白から灰色の円形グラデーションです）。
2. **アバターのマテリアルに割り当てる**
   作成した `.matcapgen` ファイルを、lilToon などのマテリアルの Matcap テクスチャ欄へドラッグ＆ドロップします。
3. **Inspector で調整する**
   Project ビューで `.matcapgen` ファイルを選択し、Inspector の各パラメータを調整します。スライダーを動かしている間もシーン上のアバターの見た目がその場で変わり、変更は自動で保存されます。

> [!NOTE]
> 作った Matcap を他の人と共有したり、別のプロジェクトへ持ち出したりする場合は、作業の最後に Inspector の「PNG として保存」から PNG へ書き出し、マテリアルに割り当て直してください（詳しくは「注意点」を参照してください）。

## テクスチャの仕組み

Matcap Generator で作るテクスチャは、次の 2 つの要素で構成されています。

- **円形グラデーション（1 枚）**: 画像の中心から外周に向かって色が変わるベース層です。モデル上では、画像の中心が「カメラ（視線）の正面を向いている面」、外周が「輪郭付近の面」に対応します。
- **デカール（0 個以上）**: グラデーションの上に重ねる、ぼけた円形の光点や影です。ツヤのハイライトや差し色を入れるのに使います。

## Inspector の項目

`.matcapgen` ファイルを選択すると、Inspector に以下の項目が表示されます。

### 基本設定

- **解像度**: テクスチャの解像度を `128` / `256` / `512` / `1024` から選びます（既定値: `512`）。

### 円形グラデーション

- **色（中心→外周）**: Unity 標準のグラデーション編集欄です。左端が画像の中心（正面を向いた面）、右端が外周（輪郭付近の面）の色になります。
- **色の広がりカーブ**: 中心から外周にかけて、どの位置で色が切り替わるかを調整するカーブです。横軸が中心からの距離、縦軸がグラデーションのどの位置の色を使うかを表します。色の変化を中心寄りに急にしたり、外周寄りに急にしたりできます。
- **距離の測り方**: グラデーションの広がり方を `視線からの角度`（既定）と `画像上の距離` から選びます。
  - **視線からの角度**: モデル上で色の帯が均等な幅で並びます。
  - **画像上の距離**: モデル上では輪郭付近の色が細くなります。

### デカール

リストの **＋** でデカールを追加、**－** で削除、左端のドラッグで順番を並べ替えられます。リストの上にある項目から順に重ねられます。

- **位置（横）・位置（縦）**: `-1` 〜 `1` の範囲で位置を指定します。画像の中心が `0` です。
- **大きさ（角度）**: 球面上の角度（度）で大きさを指定します。外周寄りに置いたデカールはテクスチャ画像上では潰れて見えますが、モデルに貼ると自然な丸い光や影として表示されます。
- **ぼかし**: 輪郭のぼかし具合です。`0` でくっきり、`1` で全体がぼけます。
- **色**: デカールの色を指定します。
- **不透明度**: デカールの濃さ（透明度）を指定します。
- **合成モード**: 下の色との重ね方を `通常` / `加算` / `スクリーン` / `乗算` から選びます。ハイライトを入れたいときは `加算` や `スクリーン`、影を落としたいときは `乗算` が便利です。

### 書き出し

- **PNG として保存**: 現在の内容をもとに、通常の PNG 画像を同じフォルダへ書き出します。同じ名前の PNG ファイルがすでにある場合は、上書きするかどうかを確認するダイアログが表示されます。

## 注意点

- **`.matcapgen` ファイル単体では他環境で復元できません**
  `.matcapgen` 形式のテクスチャは、**Matcap Generator が導入されているプロジェクトでしか読み込めません**。アバターを `.unitypackage` で他の人に渡す場合や、プロジェクトから本パッケージを削除する場合は、事前に **「PNG として保存」** で書き出した PNG ファイルをマテリアルに割り当て直してください。
- **ファイルサイズと画質について**
  生成されるテクスチャは非圧縮の 8bit RGBA です。解像度 `512` の場合、ミップマップ込みで約 1.3MB になります。
